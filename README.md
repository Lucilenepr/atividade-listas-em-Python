# 🛒 Sacolão da Generation & Revisão de Python

Este projeto foi desenvolvido como parte das atividades de revisão de Python (Semana 1). Ele simula um sistema interativo de gerenciamento de produtos (um sacolão/loja de roupas) que permite listar itens, cadastrar novos produtos com validação de preços e gerenciar o estoque utilizando estruturas fundamentais da linguagem.

## 🚀 Funcionalidades

- **Mensagem de Boas-Vindas:** Interação amigável com o usuário.
- **Listagem de Produtos:** Exibição elegante dos produtos e seus respectivos preços utilizando o método `zip()` para percorrer múltiplas listas simultaneamente.
- **Cadastro Interativo:** Permite ao usuário adicionar novos produtos e valores em tempo real, atualizando as listas dinamicamente com o método `.append()`.
- **Algoritmo de Descarte (LIFO):** Simulação de controle de estoque removendo o último elemento adicionado através do método `.pop()`.
- **Exercícios de Lógica:** Inclui desafios clássicos de programação como o **FizzBuzz** e manipulação de loops `for` com `range()`.

## 🛠️ Tecnologias e Conceitos Aplicados

- **Linguagem:** Python 3
- **Estruturas de Dados:** Listas (`lists`), Dicionários/Conjuntos.
- **Estruturas de Repetição:** `for` loops, `zip()`, `range()`.
- **Estruturas Condicionais:** `if`, `elif`, `else` para controle de fluxo e tomada de decisão.
- **Entrada e Saída:** Funções `print()`, f-strings formatadas (`f"{valor:.2f}"`) e `input()` com conversão de tipos (`int`, `float`).

## 📁 Estrutura do Código

1. **Etapa 1:** Inicialização do sistema e exibição do catálogo de produtos.
2. **Etapa 2:** Fluxo interativo para cadastro de novos produtos via terminal.
3. **Etapa 3:** Lógica de remoção de itens (LIFO) para garantir o controle do estoque.
4. **Extras:** Exercício FizzBuzz e testes práticos de indentação e escopo em Python.
